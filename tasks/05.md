Implement crash detection in Flutter using sensors_plus:

- Sample accelerometer and gyroscope at ~50 Hz
- Compute total G-force = sqrt(x²+y²+z²)/9.81, subtract gravity, and apply a low-pass filter
- Use a rolling-window buffer (last 2 seconds)
- Flag a crash when G-force > configurable threshold (default ~4G) AND there is a sudden gyroscope spike or abrupt speed drop (use GPS speed) to avoid false alarms from phone drops
- Add a cooldown so it doesn't trigger repeatedly
- Make sensitivity (Low/Med/High) configurable in settings
- Write it as a separate, testable CrashDetectionService class, with unit tests using simulated sensor data
- Add comments explaining the algorithm
