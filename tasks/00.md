Project: RESQDRIVE - smartphone-based vehicle accident detection and automated emergency response system (college OS + DBMS project).

Flow:
1. App monitors accelerometer + gyroscope continuously in the background.
2. If G-force/rotation crosses a threshold, flag a potential crash.
3. Show a full-screen "Are you okay?" alert with a 15-second countdown, siren/vibration, and a big "I'M SAFE" cancel button.
4. If the timer expires with no response, capture GPS coordinates.
5. Send incident payload to the backend via REST API; backend saves it in the database and triggers SOS alerts (SMS/push/email) to emergency contacts and a dispatch dashboard.

Stack: Flutter (mobile), Node.js + Express (REST API), PostgreSQL (DB), JWT auth.
OS concepts to demonstrate: background services/foreground service, sensor sampling, timers/threads, permissions, battery management, inter-process communication, local notifications.
DBMS concepts to demonstrate: ER design, 3NF normalization, foreign keys, indexes, transactions, triggers, views, audit logging.

Rules: clean folder structure, comments explaining OS/DB concepts, environment variables for secrets, no hardcoded keys.
